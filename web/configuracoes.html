Modo de manutenção

Deixa o painel somente leitura para quem não configura o sistema, pausa o simulador e os relatórios agendados e mostra um aviso no topo de todas as páginas.

Backups

Cópias completas do banco em .ndjson.gz. Restaure com npm run restaurar.

Retenção de dados

O que fica velho demais é removido todo dia. Os prazos vêm das variáveis BENTO_RETENCAO_*.

Monitoramento

Endereços para o orquestrador, o balanceador e o Prometheus.

/api/v1/saude/vivo
Sonda de vida: o processo responde.
/api/v1/saude/pronto
Sonda de prontidão: banco no ar, migrações em dia e sem encerramento. Responde 503 quando não está pronto.
/api/v1/metricas
Métricas no formato do Prometheus.
